# Mafia Packs

Установщик фанатских тематических наборов для режима «Мафия» в WePlay.

## Скачать приложение

Откройте раздел Releases и скачайте Mafia-Packs.apk из последнего выпуска.

## Наборы

- Губка Боб.
- Клинок, рассекающий демонов.

Для доступа к набору нужен ключ покупки. После активации приложение скачает его ресурсы.

Можно отдельно устанавливать персонажей, фоны, музыку и звуки, сочетать разделы приобретённых наборов и возвращать оригинальное оформление.

## Как начать

1. Установите Mafia-Packs.apk.
2. Откройте официальный WePlay → «Мафия» и дождитесь загрузки ресурсов.
3. В Mafia Packs активируйте ключ, скачайте и откройте набор.
4. Настройте Shizuku по инструкции внутри приложения.
5. Проверьте ресурсы и установите нужные разделы.

## Требования

Android 11 или новее, официальный WePlay 6.6.4, Shizuku и интернет. Для настройки Shizuku без компьютера нужен Wi-Fi.

## Обновление

Устанавливайте обновления поверх текущей версии. Не удаляйте приложение и не очищайте его данные, чтобы сохранить привязку покупки и резервные копии.

При ошибке откройте «Диагностика и помощь» и отправьте отчёт продавцу через ваш заказ.
